## 🚀 Panduan Menjalankan Program

Pastikan Java Development Kit (JDK 8 atau versi lebih baru) sudah terinstal dan terdaftar di PATH komputer Anda.

1. **Buka Terminal / Command Prompt** dan navigasikan ke folder materi yang ingin dijalankan, contoh:
   ```bash
   cd "pertemuan 5 d3"
   ```

2. **Kompilasi kode program**:
   ```bash
   javac Main.java
   ```

3. **Jalankan program hasil kompilasi**:
   ```bash
   java Main
   ```

*(Catatan: Jika folder mengandung beberapa file `.java` yang saling terhubung, Anda dapat mengompilasi seluruhnya secara sekaligus menggunakan perintah `javac *.java`).*

## 💡 Tips Praktikum & Prinsip Clean Code

1. **DRY (Don't Repeat Yourself)**: Hindari menuliskan baris kode atau rumus perhitungan yang identik berulang-ulang di setiap cabang `if-else`. Cukup tentukan nilainya dalam percabangan, lalu lakukan kalkulasi dan pencetakan satu kali di bagian akhir.
2. **Kerapian Indentasi**: Gunakan spasi atau tab secara konsisten agar blok kode mudah ditelusuri.
3. **Pemberian Nama Variabel (Naming Convention)**:
   - Gunakan format `camelCase` untuk nama variabel dan method (contoh: `totalBelanja`, `hitungNilaiAkhir`).
   - Gunakan format `PascalCase` untuk nama class (contoh: `KarakterGame`, `Perulangan_While`).
4. **Membersihkan Buffer Scanner**: Ketika membaca tipe angka (`nextInt()`, `nextDouble()`) sebelum membaca teks (`nextLine()`), selalu panggil `input.nextLine();` ekstra untuk membersihkan sisa enter (*newline character*) di buffer.

# Materi & Contoh Praktikum Pemrograman Berorientasi Objek (PBO)

Repositori ini berisi kode sumber, latihan, dan studi kasus praktikum **Pemrograman Berorientasi Objek (PBO)** dalam bahasa pemrograman Java. Setiap kode telah dilengkapi dengan komentar penjelasan langkah demi langkah untuk mempermudah praktikan dalam memahami konsep dasar hingga lanjutan.

---

## 📂 Struktur Direktori

### 1. `PERTEMUAN 1` - Pengenalan Dasar Java
* **`HalloWorld.java`**: Anatomi struktur dasar program Java, fungsi `public class`, `main` method, dan `System.out.println`.
* **`PerkenalanDiri.java`**: Format pencetakan data multi-baris ke console dan penggunaan escape sequence.
* **`Main.java`**: Template dasar kerangka program Java.

### 2. `pertemuan 2` - Variabel, Tipe Data, & Operator
* **`Main.java`**: Pengenalan tipe data primitif & objek (`String`, `int`, `double`) serta penggabungan teks (*String concatenation*).
* **`Oprator.java`**: Operator aritmatika (`+`, `-`, `*`, `/`, `%`), konsep *Integer Division*, dan *Type Casting*.
* **`challenge_lingkaran.java`**: Challenge perhitungan luas dan keliling lingkaran.
* **`challenge_segitiga.java`**: Challenge perhitungan luas dan keliling segitiga.

### 3. `pertemuan 3` - Scanner & Percabangan Dasar
* **`Nilai.java`**: Mengambil input keyboard dengan `Scanner` dan alur evaluasi `if - else if - else`.
* **`Ipk.java`**: Evaluasi predikat kelulusan berdasarkan skala IPK.
* **`Kalkulator.java`**: Program kalkulator sederhana dengan validasi menu dan penanganan *division by zero*.

### 4. `Pertemuan 3 d3` - Percabangan Lanjutan & Perulangan
* **`Challenges.java`**: Menu bangun datar menggunakan struktur `switch - case`.
* **`Discount.java`**: Sistem perhitungan diskon belanja bertingkat.
* **`Kalkulator.java`**: Kalkulator 4 operasi aritmatika interaktif.
* **`percabangan.java`**: Konversi nilai angka ke grade huruf A - E.
* **`Tess.java`**: Contoh implementasi alternatif kalkulator bersih.
* **`Tess2.java`**: Perbandingan struktur perulangan `for`, `while`, dan `do-while`.

### 5. `pert 4 d3` - Studi Kasus Diskon Kasir & Fondasi PBO
* **`Kuis.java`**: Kuis sistem kasir diskon member berbasis compound boolean condition (`&&`).
* **`SistemDiskonKasir.java`**: Sistem kasir diskon member berbasis **Nested If** (Percabangan Bersarang).
* **`Tess.java`**: Penerapan prinsip **Clean Code & DRY (Don't Repeat Yourself)** pada perhitungan kasir.
* **`Main.java`**: Pengenalan konsep OOP (Class, Object/Instance, Constructor, Atribut, Method, dan keyword `this`).

---

## 🚀 Cara Menjalankan Program

Pastikan JDK (Java Development Kit) sudah terinstal di komputer Anda.

1. Buka terminal / command prompt dan masuk ke direktori file:
   ```bash
   cd "pertemuan 2"
   ```

2. Kompilasi file Java:
   ```bash
   javac Oprator.java
   ```

3. Jalankan program hasil kompilasi:
   ```bash
   java Oprator
   ```
